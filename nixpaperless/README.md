# nixpaperless — Paperless-ngx (CT 115)

Document management for the household: scans from the multifunction printer
land in the consume directory (or are dragged into the web UI), get OCR'd,
classified and full-text searched.

* URL: <https://paperless.minnecker.com> (wildcard cert, proxied by `nixnginx`)
* Container: `nixpaperless`, CT **115**, `10.20.20.25` / `fd01::25`, rootfs
  `fast:24G`, 2 cores / 3 GB
* App: `services.paperless` (paperless-ngx **2.20.15**), four units —
  `paperless-scheduler` (celery beat), `paperless-task-queue` (celery workers),
  `paperless-consumer` (the watcher), `paperless-web` (granian on port 8000)
* Database: PostgreSQL **on `nixpostgresql`** (role/db `paperless`)
* Cache/queue: the redis instance the module starts automatically
  (`services.redis.servers.paperless`, unix socket) — no shared redis
* Files: `/var/lib/paperless/{data,media,uploads,consume}` on the container's
  own ZFS volume, covered by the nightly restic pass through `vzdump 115`

## Secrets

| What | Where | Why |
| :--- | :--- | :--- |
| DB password | host `/var/lib/secrets/postgres/paperless/db-password`, bind-mounted `ro` into CT 115 | shared secret: `nixpostgresql` is the sole writer (`postgres-provision-passwords` derives it from `ensureUsers`) |
| Django `SECRET_KEY` | `/var/lib/paperless/nixos-paperless-secret-key` (0400, `paperless`) | container-local; generated by `paperless-web` on first start and backed up with the volume |

`paperless-secrets` (oneshot, `wantedBy` + `before` all four units) assembles
`/run/paperless/env` with `PAPERLESS_DBPASS` on every start. The file is not
optional for systemd, so a missing mount stops the stack loudly instead of
letting paperless come up half-configured.

## Create the container

```bash
pct create 115 local:vztmpl/nixos-image-lxc-proxmox-26.05pre-git-x86_64-linux.tar.xz \
  --hostname nixpaperless --ostype nixos --unprivileged 1 --features nesting=1 \
  --storage fast --rootfs fast:24 --cores 2 --memory 3072 --swap 2048 \
  --onboot 1 --startup order=2 \
  --net0 name=eth0,bridge=vmbr1,gw=10.20.20.1,gw6=fd01::1,ip=10.20.20.25/24,ip6=fd01::25/64
```

Then append the shared-password mount (LXC config, applied on container
**start**):

```ini
lxc.mount.entry: /var/lib/secrets/postgres/paperless var/lib/secrets/postgres/paperless none bind,ro 0 0
```

Inside the container, the usual git flow:

```bash
git clone https://github.com/floffel/nix.git /root/nixos-config
nix-channel --add https://channels.nixos.org/nixos-26.05 && nix-channel --update
ln -s /root/nixos-config/nixpaperless/configuration.nix /etc/nixos/configuration.nix
ln -s /root/nixos-config/common-lxc.nix /etc/nixos/common-lxc.nix
ln -s /root/nixos-config/hosts.nix /etc/nixos/hosts.nix
cd /root && nixos-rebuild switch
```

## Blank-page removal (`del_empty_pages`)

`PAPERLESS_PRE_CONSUME_SCRIPT` points at `nixpaperless/del-empty-pages.sh`,
wrapped by a store derivation that provides bash, `file`, ghostscript,
`pdfinfo` and `qpdf` on `PATH`. Scanners feed blank or near-blank pages
(threshold: 0.9 % printed ink coverage); the script drops them before the page
is OCR'd and stored, which is what kept the archive lean on the old machine.

Paperless execs the script directly, so the wrapper's `#!/bin/bash` shebang and
its `PATH` are both load-bearing — the script uses `set -o pipefail` and five
external tools that a hardened paperless unit does not otherwise carry.

## Migration from saver CT 110 (2026-11-02)

The old install was a native Arch setup: venv at `/usr/lib/paperless`, config at
`/etc/paperless.conf`, **SQLite** at `/var/lib/paperless/data/db.sqlite3`,
valkey, four systemd units under `paperless.target`, version 2.20.3.

Steps taken (`document_exporter`/`document_importer` is the supported path
across databases, and the manifest is a full Django dump — users, groups,
permissions, saved views, correspondents, tags, custom fields):

```bash
# 1. old box: quiesce, then export (documents + thumbnails + DB manifest)
pct exec 110 -- systemctl stop paperless.target
pct exec 110 -- sudo -u paperless /usr/lib/paperless/bin/python \
  /usr/share/paperless/src/manage.py document_exporter /root/paperless-export

# 2. stream to px, then import into the empty Postgres DB
pct exec 115 -- systemctl stop paperless-scheduler paperless-web \
  paperless-task-queue paperless-consumer
pct exec 115 -- sudo -u paperless paperless-manage document_importer /root/paperless-import
pct exec 115 -- systemctl start paperless-scheduler
```

Deliberate changes during the move:

* SQLite → PostgreSQL (repo convention; the consumer and the web UI contend on
  SQLite writes as soon as more than a handful of documents arrive).
* `paperless-ngx` 2.20.3 → 2.20.15 (whatever the pinned nixpkgs carries).
* `PAPERLESS_WEBSERVER_WORKERS` 4 → 2 (two cores).

Deliberate **non**-changes: OCR language stays at the default `eng`, because
that is what the old install ran with and nixpkgs' `tesseract` only ships
English language data by default — adding `deu` needs a package override, not a
settings line.

Rollback: `saver` CT 110 is untouched and still boots
(`systemctl start paperless.target`), and the export directory stays on the
laptop and on `px` until the retirement of `saver` is signed off.
